# 미션! 여리고 가는 길

누가복음 10장에서 출발한 가상의 선택형 이야기 게임입니다. 제사장, 사마리아에서 온 여행자, 대추야자 상인의 입장에서 약속과 이웃 돌봄 사이의 선택을 경험합니다.

## 실행

[게임 열기](https://ryuyh0223-art.github.io/bible-storybook/jericho-worship/)

로컬에서는 이 폴더의 `index.html`을 브라우저로 열면 됩니다. `assets`, `style.css`, `game.js`를 함께 보관해야 합니다. 외부 CDN이나 서버 API에 의존하지 않습니다.

## 조작

- 마우스 클릭 또는 화면 터치로 역할·선택지·다음 버튼을 누릅니다.
- 숫자 1–3: 역할 선택, 숫자 1–2: 선택지 선택.
- Enter / Space: 다음 대사. 버튼에 초점이 있으면 해당 버튼을 실행합니다.
- R: 처음으로. F: 전체화면 진입·종료. Esc: 브라우저의 전체화면 종료.
- Tab / Shift+Tab: 버튼 사이 이동.
- 전체화면을 지원하지 않는 브라우저에서는 전체화면 버튼이 숨겨집니다.

## 화면 구성

PC는 기존 16:9 구도를 유지합니다. 휴대폰 세로 화면과 높이가 낮은 작은 가로 화면에서는 그림 전체를 보여주고 그 아래에 대사와 선택지를 배치합니다. 작은 화면에서는 세로 스크롤로 모든 내용을 읽을 수 있습니다.

## 변경 사항

- 모바일에서 지나치게 작던 글씨와 버튼을 읽고 누르기 쉬운 크기로 수정했습니다.
- 엔딩 제목의 줄 높이와 패널 여백을 조정했습니다.
- 초광폭 PC 전체화면에서 게임 비율이 깨지고 버튼이 잘리는 문제를 수정했습니다. 바깥 영역을 전체화면으로 열고 게임의 16:9 비율을 유지합니다.
- 버튼에 초점이 있을 때 Enter / Space가 전역 단축키와 충돌하지 않도록 수정했습니다.
- 키 반복과 Ctrl / Alt / Meta 조합을 전역 단축키에서 제외했습니다.
- 전체화면 상태 및 실패를 처리하고 버튼의 접근성 이름을 보강했습니다.
- 장면 그림을 미리 읽고 디코딩한 뒤 화면과 대사를 함께 바꿔 로딩 중의 깜빡임을 방지했습니다.
- 아침 자막은 하나만 표시하며, 1.6초 동안 대사와 진행 입력을 잠시 멈춰 글씨 중첩과 장면 건너뛰기를 방지합니다.
- 원본의 그림을 재생성하거나 화질을 변경하지 않고 별도 파일로 분리했습니다. 중복 그림 1개를 공유하여 62개 그림 참조가 61개 파일을 사용합니다.

## 점검 및 개선 아이디어

검사 범위와 한계는 [QA_REPORT.md](QA_REPORT.md)를 참고하세요.

Chrome이 설치된 환경에서 `npm install` 후 `npm test`를 실행하면 전체 브라우저 검사를 재현할 수 있습니다. `qa/results.json`에 결과가, `qa/*.png`에 화면 캡처가 저장됩니다. 테스트용 의존성은 게임 실행에 필요하지 않습니다.

`npm run test:transitions`는 PC·휴대폰에서 아침 자막 12가지 경우와 느린 그림 로딩, 로딩 중 초기화, 모션 줄이기를 별도로 검사합니다. 전체 경로 검사는 모션 줄이기를 사용하고 자막 검사는 일반 모션으로 실행합니다.

- 이어하기: 중간에 닫아도 마지막 선택부터 재개하는 저장 기능.
- 엔딩 회고: 선택한 물품·이동·돌봄 방법을 마지막에 돌아보는 카드.
- 함께 나누기: 마지막 질문에 부모·교사용 대화 질문 2–3개 추가.
- 그림의 분기 표현: 공통으로 쓰는 주막·엔딩 그림에도 물품 선택 결과를 더 세밀하게 반영하는 추가 원화.

위 아이디어는 제안이며 현재 이야기와 엔딩 내용은 유지했습니다.
